## 0. 一句话目标

- **轮值系统**：既能支持我们班的“值周制”（分组、组内每人固定任务、做一周、每周换组），也能支持普通“值日制”（每天换人）；岗位、人数、班委、课代表全部可自定义，并提供配置向导。
- **单双周课表**：同一张课表支持单周/双周不同安排；默认以“开学第一周为单周”自动推算，也可自选任意第一周、手动覆盖当前周。

---

## 1. 背景与设计原则

1. **高度自定义是初衷**：不写死岗位/人数/职位；预设只是模板，全部可改可删。
2. **默认值可用**：不配置也能用（空模板 + 引导），配置完立即生效。
3. **不破坏现有数据**：v1.3 的课表、花名册、备份继续可用；关闭新功能时行为与 v1.3 完全一致。
4. **宠物和桌面是主界面**：轮值信息尽量常驻在宠物课表面板 / 折叠态里，提醒走气泡（不抢焦点、不挡 PPT）。
5. **打印/提醒可关闭，但功能必须存在**。

---

## 2. 术语与范围

| 术语 | 含义 |
| --- | --- |
| 值周 | 一组人负责整整一周，每周轮换到下一组；组内每人有固定岗位（如张三固定擦黑板） |
| 值日 | 每天安排若干人，岗位可以每天轮换 |
| 固定任职 | 班委、各科课代表等长期固定的岗位，不参与轮换 |
| 轮值组 | 值周/值日里的一组学生，可自动按学号分，也可手动拖拽 |
| 岗位 | 一件具体工作，例如“擦黑板”“倒垃圾”“语文课代表”“纪律委员” |
| 单双周 | 单周与双周使用不同课表安排（如单周多一节自习、双周多一节听力） |
| 锚点周 | 单双周推算的起点周（通常是开学第一周，定义它是单周） |

# 第一部分：值周 / 值日 / 固定任职

## 3. 概念模型

```
轮值系统
├── 模式（全局二选一，可随时切换）
│   ├── 值周制：组 → 做一周 → 下周换下一组；组内成员岗位固定
│   └── 值日制：每天若干人 → 每天轮换；岗位按当天的分配
├── 岗位库（自定义名称、分类、人数）
├── 轮值组（值周模式专用；值日模式可选“按组轮”）
├── 固定任职（不轮换）
│   ├── 班委（类型 / 人数 / 成员，均可自定义）
│   └── 课代表（按科目，人数可自定义）
├── 提醒（早读前 / 放学前 / 换周前，可开关）
├── 打印/导出（可开关）
└── 打卡记录（可选，接课堂积分/养成）
```

## 4. 岗位库（Tasks）

| 字段 | 说明 |
| --- | --- |
| `Id` | 唯一标识 |
| `Name` | 岗位名，如“擦黑板” |
| `Category` | 分类：卫生 / 值周 / 班委 / 课代表 / 其他（用于分组展示与预设） |
| `RequiredCount` | 每班需要几人（0 表示停用） |
| `Note` | 说明（打印时可显示） |
| `Sort` | 排序 |

- 完全自定义：名称、人数、增删改、拖拽排序。
- 预设包（向导里勾选，生成后仍可改）：

**卫生值日包**：擦黑板 1、讲台 1、扫地 2、拖地 2、倒垃圾 1、摆桌椅 1、门窗 1、卫生角 1
**值周包**：擦黑板 1、讲台整理 1、扫地 2、拖地 2、倒垃圾 1、门窗 1
**班委包**：班长 1、副班长 1、团支书 1、学习委员 1、纪律委员 1、卫生委员 1、体育委员 1、文艺委员 1、宣传委员 1、生活委员 1、心理委员 1、电教管理员 1
**课代表包**：语文、数学、英语、物理、化学、生物、政治、历史、地理各 1（可改 0～4 人）
**空模板**：什么都不预设，自己加。

> 预设数量只是常见写法，用户随时可改；不确定学校岗位时也可以先建空模板。

## 5. 值周制（我们班当前的做法）

### 5.1 配置项

- **分组**：把当前花名册分成 N 组（按学号顺序自动分 / 随机分 / 手动拖拽），组名可改（第1组、第2组…）。
- **轮换顺序**：默认 1→2→3→…→N→1；可拖拽调整。
- **起始周**：第一个值周组从哪一周开始（默认本周一；可指定日期）。
- **组内固定任务**：每个组内：成员 ↔ 岗位的固定对应关系。
  - 向导可“按岗位顺序自动分配组员”，也支持手动拖拽。
  - 允许一人多岗；允许“机动/待命”不设岗位。
  - 允许某个岗位由 2 人共同负责（岗位 RequiredCount=2）。
- **周次显示**：第 X 周（第 Y 轮）。不启用“跳过周”时按自然周连续轮换。

### 5.2 排班算法

```
weekIndex = floor((本周一 - 起始周一) / 7 天)
组 = 轮换顺序[weekIndex mod N]
本周任务 = 该组的固定分配（成员 → 岗位）
```

- 支持**手动覆盖某周**：如考试周换成别的组 / 暂停值周 / 换成“卫生只做黑板”。
- 支持**暂停周**：考试周、运动会周等不安排值周（记录原因），下周继续轮换。

### 5.3 展示

- 宠物课表下方常驻行（可开关）：
  - 值周模式：`本周值周：第 3 组`
  - 展开时显示本周组内岗位表（可折叠）
- 仪表盘“本周轮值”卡片：值周组 + 岗位清单 + 下周预告。
- 新窗口「值日与轮值 → 本周」：本周岗位表、换人、暂停/覆盖、打印。

## 6. 值日制（普通班级做法）

### 6.1 配置项

- **每天人数**：如每天 4 人。
- **每日岗位**：沿用岗位库，可设置“每天固定岗位组合”（例如 黑板、扫地、垃圾、讲台）。
- **轮换规则**（三选一）：
  1. **按学号顺序轮**：每天取名单里接下来的 K 人（一轮内每人次数差 ≤1）；
  2. **按小组轮**：小组整体每天轮换（组内再按岗位顺序分配）；
  3. **手动排**：直接指定某天哪些人做什么。
- **起始日期**与**每日轮换起点**（默认本周一）。
- 支持**请假/临时换人**：只改当天，记录历史（谁替了谁）。

### 6.2 排班算法

```
dayIndex = 天数差(目标日期, 起始日期)
当天人员 = 名单按顺序取 [dayIndex*K mod 人数 ...]（循环）
当天任务 = 每日岗位组合按顺序分配给当天人员
```

- 同日多岗位时，按岗位顺序循环分配给当天人员。
- 有手动排班时，手动数据优先。

## 7. 固定任职：班委与课代表

### 7.1 班委

- 职位类型可新增/重命名/删除，每个类型人数可设 0～4。
- 每个职位绑定花名册成员（可空）。
- 预设：见上文“班委包”；预设不是写死的，只是生成一份可编辑的配置。

### 7.2 课代表

- 按科目维护：科目名称可增删（默认九科 + 体育/音乐/美术/信息/通用技术/心理，可改）。
- 每个科目人数可设 0～4，绑定成员。
- 课代表是**固定任职**，不参与轮换（用户确认）。

### 7.3 配置向导（Wizard）

入口：设置 / 值日窗口 / 首次打开该功能时。

步骤：

1. **选择模式**：值周制 / 值日制
2. **选择岗位包**：勾选预设包或空模板（可多选合并），然后进入“岗位与人数”页微调
3. **分组**（值周模式）：组数、分组方式（按学号 / 随机 / 手动），确认每组名单
4. **组内任务分配**：自动按顺序分配，可拖拽修改；右侧显示“未分配岗位/未分配人员”提示
5. **班委 / 课代表**：勾选职位与人数（可选“稍后配置”）
6. **提醒与打印**：开关、时间点、打印标题
7. **完成预览**：本周与下周安排预览；点“完成”保存

> 向导每一步都可“跳过”，保存后仍能在窗口里改。

## 13. 边界与异常

- 岗位/组/成员为空：显示引导，不排班、不提醒。
- 组成员 < 岗位人数：允许一人多岗，提示“建议增加人员”。
- 某一周暂停：该周无安排，气泡不提醒；下周继续按轮换顺序（暂停周计入周数但不安排人，避免以后整体错位）。
- 临时换人只影响当天/当周，历史可查；撤销后恢复自动排班。
- 学期更换：可“重置排班”（清空覆盖与打卡，保留岗位/分组配置）。
- 打印时成员/岗位为空：打印空模板提示。
- 关闭功能：宠物面板行消失、不提醒；数据保留，重开即恢复。

## 14. 验收标准（值日部分）

1. 值周模式：4 组、每周一 00:00 自动换组，第 1 周第 1 组、第 2 周第 2 组；组内任务固定显示正确。
2. 值日模式：按学号轮，每人次数差 ≤1；同一天多人多岗分配正确。
3. 岗位/班委/课代表增删改、人数修改后立即生效并持久化。
4. 向导从空配置生成一套可用排班（值周/值日各一遍）。
5. 请假换人只改当天，历史可见；撤销恢复。
6. 提醒按设定时间弹气泡一次；关闭提醒后不弹；气泡样式与 v1.3 一致。
7. 打印预览 A4 正常（纵/横版），CSV 导出内容正确；打印开关关闭后入口隐藏。
8. 备份/恢复包含 duty.json，数据不丢。

# 第二部分：单双周课表

## 15. 单双周定义与推算

- 设置项：
  - `EnableWeekParity`（默认 **关**）
  - `WeekParityAnchorDate`：锚点周的**周一**（默认“本学期第一周星期一”；提供快捷“以本周为第 1 周”）
  - `FirstWeekIsOdd`：锚点周是单周（默认是）
  - `ShowWeekNumberOnPet`（默认开）
- 推算：
  ```
  weekIndex = floor((目标周一 - 锚点周一).Days / 7)
  周次 = weekIndex + 1
  单双周 = 锚点周单双周 按 weekIndex 奇偶翻转
  ```
- **手动覆盖**：设置里可选“本周按：自动 / 单周 / 双周”，只影响当前周（下周自动恢复自动）；用于调休、考试周。
- 显示示例：`第 6 周 · 双周`（宠物面板标题行/折叠态）。

## 16. 课表数据模型扩展

### 16.1 课程条目增加“周类型”

`TimetableEntry` 增加：

```csharp
public enum WeekType { All = 0, Odd = 1, Even = 2 }

public WeekType Weeks { get; set; } = WeekType.All;   // 默认通用，兼容旧数据
```

- `WeekTimetable.SchemaVersion` 从 1 → 2；旧文件读取时缺失字段按 `All` 处理。
- 同一 (星期, 节次) 最多允许：`All` 1 条 + `Odd` 1 条 + `Even` 1 条。

### 16.2 课程解析优先级（从高到低）

1. 当天临时换课/取消（`DayOverride`，已有功能）
2. 与当前单双周匹配的专用条目（Odd 或 Even）
3. 通用条目（All）
4. 无 → 显示“未设置”

新增重载：

```csharp
string? CourseAt(DayOfWeek day, int periodIndex, WeekParity parity);
IReadOnlyList<CourseOccurrence> BuildOccurrences(..., WeekParity parity);
```

## 17. 课表编辑器 UI

- 未启用单双周：保持现状（一套课表）。
- 启用后：编辑器顶部出现页签 **「通用」「单周」「双周」**
  - **通用**：两边都用的课（默认页签，改动自动同步到两边）
  - **单周 / 双周**：只填与通用不同的格子
  - 格子中若已有通用课但此周要改：直接编辑生成专用条目；提供“恢复为通用”
  - 工具：`把通用复制到单周`、`把通用复制到双周`、`清空单周/双周专用项`
- 冲突提示：同一格单周和双周可以不同；同周类型重复条目时提示并保留最后编辑。

## 23. 边界与异常

- 锚点日期在将来/过去：正常计算（周次可为负数，显示“第 -2 周”？改为“开学前”或隐藏周次，具体以确认稿为准）。
- 锚点不是周一：自动对齐到该日期所在周的周一，提示用户。
- 关闭单双周后：单周/双周专用条目仍保存在文件中，重新开启后恢复；显示全部按通用（专用忽略），避免“看不见的数据”误导——编辑器里仍能看到并提示。
- 跨年、闰周：按周一日期差计算，不依赖日历周编号。
- 调休/放假：用“本周手动覆盖”解决；不做自动节假日库。

| A4 | 班委/课代表的预设：用户不确定 → **第一次配置时弹窗让用户选择用哪个预设，或者不用预设**；选完仍可编辑 |

| A9 | 入口：菜单 + 仪表盘卡片 + 设置向导入口 + 首次配置弹窗，均可 |

## D. 据此简化/调整的设计

1. **轮值引擎统一为“分组轮换”**：
   - 配置：`Mode = Weekly | Daily`；组列表（成员固定）；任务库；每组的任务分配（固定/自动两种策略）；轮换起点（周次/日期）。
   - 周期：Weekly = 每周换组；Daily = 每天换组。不再做“按学号每日轮换”的独立模式。
2. **岗位人数可覆盖**：任务默认人数 + 每组可额外指定“这个岗位本组几个人”，允许一个岗位 2 人；允许一人多岗。
3. **不再有打印相关 UI/数据**；窗口/仪表盘的“复制文本”用作发班级群。
4. **放学后展示**：`DutyDisplaySettings` 增加：`AfterSchoolMinutes = 60`、`BlackboardTopKeywords = ["擦黑板","黑板","讲台"]`、`ShowAfterSchoolInfo = true`；宠物面板在放学到放学后 60 分钟内用轮值信息替换课表内容，之后恢复“已放学”。
5. **首次配置向导必填项**：开学第一周（周一日期）→ 同时作为值周轮换起点与单双周锚点；非完成不可跳过。
6. **不做打印**后，`DutyConfig` 中删除 Print 配置；只保留 `Display` 与 `Reminders`。
